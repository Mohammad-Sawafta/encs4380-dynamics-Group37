Digital equation and implementation notes
      
At sample k, the controller uses u[k] = Kp e[k] + Ki Ts sum(e[j]) + Kd (e[k] - e[k-1]) / Ts. The command is clipped and then held constant while RK4 advances the plant to the next sample. Unlike P1 and P2, this module deliberately differentiates error to match the homework equation.

      
With anti-windup enabled, a saturated update is rejected only when the error would drive the integral farther into saturation. Integration resumes automatically when the error reverses or the command returns inside the limits.
