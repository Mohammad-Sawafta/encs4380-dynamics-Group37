Why control wheel speed?

Each drive motor turns one Micromouse wheel. Reliable speed regulation helps the robot travel straight, execute repeatable turns, and correct motion consistently as battery voltage and load change. This page uses RPM for encoder-derived shaft speed and percent for a unidirectional PWM command from 0% to 100%.

An encoder provides pulse counts over a known time interval. Convert counts to revolutions using the measured encoder resolution and gearing, then convert revolutions per interval to RPM. No encoder resolution, gear ratio, pin, or motor-driver API is assumed here.

1 · Plant identification

PWM step test

Apply a safe constant PWM baseline, wait for steady speed, then step to a second PWM value while recording timestamped encoder speed. For G(s) = K / (τs + 1), the steady speed change gives K = Δspeed / ΔPWM; τ is the time after the step when speed reaches 63.2% of its total change.

Measurement procedure and assumptions
  1. Raise the robot so the wheel can rotate safely, or use an appropriate test fixture.
  2. Record baseline PWM and steady baseline speed. At the recorded step time, change PWM once and hold it.
  3. At each interval, convert encoder counts to RPM using the real counts-per-revolution and gear ratio.
  4. Continue long enough to reach a visibly steady tail. Enter raw time/speed pairs without relabeling simulated values as measurements.

The fit assumes a stable positive-gain first-order motor over this operating range. Dead zones, battery sag, friction, load changes, noise, and nonlinear driver behavior can reduce fit quality.

3 · Design check

Micromouse speed specifications

The limits scale with the identified motor: rise time ≤ max(0.15 s, 1.5τ), settling time ≤ max(0.5 s, 4τ), overshoot ≤ 10%, and steady-state error ≤ max(1 RPM, 2% of target). Fast, low-overshoot speed response supports straight travel and repeatable cell-to-cell motion without demanding impossible PWM.

Damping-ratio derivation and limits

For the ideal continuous controller C(s) = Kp + Ki/s + Kd s and motor G(s) = K/(τs + 1), the unity-feedback characteristic polynomial is (τ + K Kd)s² + (1 + K Kp)s + K Ki. When Ki > 0, matching a s² + b s + c to s² + 2ζωns + ωn² gives ωn = sqrt(K Ki / (τ + K Kd)) and ζ = (1 + K Kp) / (2 sqrt((τ + K Kd) K Ki)). The displayed ζ is therefore a continuous linear approximation only; digital sampling, saturation, anti-windup, derivative discretization, and real motor nonlinearities are not included. The actual simulated metrics determine pass/fail for time-domain requirements.
